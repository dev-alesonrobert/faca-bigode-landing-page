# Faca&Bigode — Landing Page

Landing page oficial do **Faca&Bigode**, uma plataforma SaaS desenvolvida para facilitar a gestão de barbearias.

## ✂️ Sobre o projeto

O Faca&Bigode reúne ferramentas para ajudar barbearias a gerenciar:

- 📅 Agendamentos
- 👥 Clientes
- 💈 Barbeiros
- ✂️ Serviços
- 📊 Resultados e desempenho
- 💰 Gestão do negócio

A landing page foi desenvolvida com uma identidade visual **dark, moderna e premium**, utilizando tons de preto, branco e roxo.

## 🎨 Características

- Design moderno e minimalista
- Dark mode
- Identidade visual em roxo
- Layout responsivo
- Seção de apresentação do produto
- Demonstração da plataforma
- Recursos e benefícios
- Planos
- Depoimentos
- FAQ
- Call-to-actions focados em conversão
