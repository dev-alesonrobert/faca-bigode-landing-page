# 🚀 Landing Page

Landing page moderna, responsiva e otimizada para apresentação de produtos, serviços ou projetos. O projeto foi desenvolvido com foco em **design moderno, organização do código e experiência do usuário**.

## 🖥️ Demonstração

🌐 **Acesse o projeto online:**
https://facaebigode.com.br

---

## 📌 Sobre o projeto

Este projeto consiste em uma landing page desenvolvida para apresentar informações de forma clara e atrativa, utilizando uma interface responsiva e adaptada para diferentes tamanhos de tela.

O objetivo é oferecer uma página rápida, moderna e visualmente agradável, podendo ser utilizada para divulgação de produtos, serviços, empresas ou projetos pessoais.

## ⚙️ Como executar o projeto

### 1. Clone o repositório

```bash
git clone https://github.com/seu-usuario/seu-repositorio.git
```

### 2. Acesse a pasta

```bash
cd landing
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
ng serve
```

Depois, abra no navegador:

```text
http://localhost:4200
```

---

## 📦 Build para produção

Para gerar a versão otimizada do projeto:

```bash
ng build
```

Os arquivos de produção serão gerados na pasta:

```text
dist/
```

## 🚀 Deploy

O projeto pode ser publicado utilizando a **Vercel**.

Após conectar o repositório do GitHub à Vercel, cada novo `push` para a branch configurada pode gerar automaticamente uma nova implantação.

### Fluxo de atualização

```bash
git add .
git commit -m "Atualiza landing page"
git push origin master
```

A Vercel realizará o novo deploy automaticamente, caso o projeto esteja configurado para acompanhar essa branch.
